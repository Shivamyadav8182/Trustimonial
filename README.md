Getting Started

Prerequisites

Install Node.js and Git before starting.

1. Clone the repository

git clone https://github.com/Shivamyadav8182/Trustimonial.git
cd Trustimonial

2. Install dependencies

npm install

3. Start the development server

npm start

Open http://localhost:3000 in your browser. The development server reloads when you save changes.

Available Scripts

Command

Description

npm start

Runs the app in development mode.

npm run build

Creates an optimized production build in the build folder.

npm test

Runs the test runner in interactive watch mode.

npm run deploy

Builds the app and publishes the build folder to the gh-pages branch.

Customization

To customize the slider, edit the relevant files in src/:

Update the testimonial data to change names, roles, profile images, and review text.

Update the React components to change slider navigation or the random Surprise Me behaviour.

Update the CSS files to change colours, spacing, card design, and responsive layout.

File names and component names depend on the current project implementation.

Deployment to GitHub Pages

This project is configured to deploy using the gh-pages package.

Confirm that the homepage field in package.json matches the repository URL:

"homepage": "https://shivamyadav8182.github.io/Trustimonial"

Publish the production build:

npm run deploy

In the GitHub repository, open Settings → Pages and set:

Source: Deploy from a branch

Branch: gh-pages

Folder: /(root)

Save the settings and wait a few minutes for GitHub Pages to publish the site.

Live site: https://shivamyadav8182.github.io/Trustimonial/

Troubleshooting

The page shows 404: Check that GitHub Pages uses the gh-pages branch and /(root) folder, and confirm the repository name matches the homepage path.

Changes do not appear: Run npm run deploy again after saving your changes, then refresh the live site.

Build fails: Read the terminal error, fix the reported issue, and rerun npm run build.
